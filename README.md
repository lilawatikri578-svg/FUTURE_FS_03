# FUTURE_FS_03
# 🍴 Indian Flavours

A Full Stack Restaurant Management Website developed using **Node.js, Express.js, EJS, MySQL (Aiven Cloud)** and deployed on **Render**.

---

## 📌 Project Overview

Indian Flavours is a modern restaurant management web application where customers can explore the restaurant, view the menu, book a table, and contact the restaurant. The project uses a cloud MySQL database hosted on Aiven and is deployed on Render.

---

## 🚀 Features

- 🏠 Home Page
- 🍽️ Menu Page
- ℹ️ About Page
- 🖼️ Gallery Page
- 📅 Table Booking System
- 📩 Contact Form
- 👨‍💼 Admin Login Page
- 📊 Admin Dashboard
- ☁️ MySQL Cloud Database (Aiven)
- 🌐 Live Deployment on Render

## ⚙️ Installation

Clone the repository

```bash
git clone  https://github.com/lilawatikri578-svg/FUTURE_FS_03.git
```

Go to project folder

```bash
cd FUTURE_FS_03/Indian-Flavours
```

Install dependencies

```bash
npm install
```

Start the server

```bash
npm start
```

or

```bash
node server.js
```

---

## 🔐 Environment Variables

Create a `.env` file inside the project folder.

```
DB_HOST=your_host
DB_PORT=your_port
DB_USER=your_user
DB_PASSWORD=your_password
DB_NAME=your_database
PORT=3000
```
